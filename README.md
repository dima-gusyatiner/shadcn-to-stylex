# shadcn/ui → StyleX — a field guide

A **standalone slide course** for engineers moving from the shadcn/Tailwind world to
[StyleX](https://stylexjs.com) (+ React Aria Components, tokens-as-modules, and the rest
of a modern design-system stack).

**One hand-written HTML file. No build step. No dependencies. No network requests.**

## ▶ View it live

**https://dima-gusyatiner.github.io/shadcn-to-stylex/**

Every slide is deep-linkable — e.g. [the cheat sheet](https://dima-gusyatiner.github.io/shadcn-to-stylex/#29)
or [the interactive merge playground](https://dima-gusyatiner.github.io/shadcn-to-stylex/#10).

## Run it locally

- Open `index.html` in a browser. That's it.
- Or serve it: `npx serve .`

## What's inside (30 slides)

| Chapter | Covers |
| --- | --- |
| 0 · The course | Same jobs / new owners, the six mental shifts |
| 1 · Where you're coming from | What a shadcn component is made of; what Tailwind actually is |
| 2 · How StyleX works | The compiler, atomic CSS math, and a **live merge-model playground** |
| 3 · The mental shifts | Strings → data · cascade → call-site order · config → token modules · className → typed contracts · copy → consume · freedom → constraints |
| 4 · The cookbook | Layout, states, responsive, dark mode/themes, variants (cva → objects), composition, animation & dynamic values |
| 5 · The rest of the stack | Radix → React Aria mapping, the monorepo, compiler/eslint wiring |
| 6 · Tradeoffs & landing | What you'll honestly miss, day-one gotchas, **the cheat sheet** |
